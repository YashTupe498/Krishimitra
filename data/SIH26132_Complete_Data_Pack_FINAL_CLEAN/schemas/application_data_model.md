# Application Data Model

## Core entities
Farmer -> ProduceLot -> QualityAssessment -> MarketSnapshot -> Opportunity -> FeasibilityCheck -> Constraint -> Resolution -> Offer -> LogisticsPlan -> PaymentTracking -> GrievanceTicket

## Decision formula
Expected Net = gross revenue - transport - storage - handling - market/transaction costs - aggregation costs - financing costs.

The LLM may extract farmer inputs and explain results. It must not invent market prices,
availability, buyer demand, payment terms or recommendation calculations.

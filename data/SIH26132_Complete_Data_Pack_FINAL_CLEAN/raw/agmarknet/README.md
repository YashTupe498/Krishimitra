# AGMARKNET Market Data

This folder contains the normalized Maharashtra Onion market records used in the project.

- `maharashtra_onion_nashik_markets_2026.csv` — populated market-price records.
- `PUT_REAL_DOWNLOADS_HERE.md` — original acquisition placeholder.

The same normalized dataset is also retained under `raw/enam/agmarknet_dashboard/` for compatibility with the e-NAM dashboard schema layer.
